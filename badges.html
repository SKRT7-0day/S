Discord Badges Lookup

Enter any Discord user ID to see their account age and official badges.

Note: Account age is calculated directly from the Discord ID and is always accurate. Official badges (Staff, HypeSquad, Bug Hunter, Nitro, etc.) require a backend bot lookup — if that's not connected yet on this deployment, only account age will show. Exact Nitro subscription dates and server-boost history aren't available through Discord's public API for arbitrary accounts, so they're intentionally left out here.
